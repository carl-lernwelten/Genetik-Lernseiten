## Veröffentlichen
1. Alle Dateien aus dem Projekt ins Repository legen — außer den in `.gitignore` genannten.
   Notwendig sind: `index.html`, die acht Themenseiten, `support.js`, `image-slot.js`, `assets/`, `_ds/`, `.nojekyll`.
2. In den Repository-Einstellungen unter *Pages* als Quelle Branch `main`, Ordner `/ (root)` wählen.
3. `.nojekyll` muss im Repository bleiben, sonst liefert GitHub Pages den Ordner `_ds/` nicht aus und die Seiten erscheinen ohne Gestaltung.
